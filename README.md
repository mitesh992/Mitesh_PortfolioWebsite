# Mitesh Rana — Personal Portfolio Website

A responsive personal portfolio created for IT4048: Version Control with Git and GitHub.

## Technologies
- HTML5
- CSS3
- JavaScript
- Git and GitHub
- GitHub Pages

## Run locally
Open `index.html` in a browser, or use the Live Server extension in VS Code.

## Before submission
1. Check the résumé file exists at `assets/resume/MITESH_RANA_RESUME.pdf`.
2. Replace the project links in `index.html` with the actual repository links for each project, if available.
3. Add a profile photo if desired; the current design uses a code-themed illustration.
4. Test all links and the résumé download.
5. Push to a public GitHub repository named `Mitesh_PortfolioWebsite`.
6. Enable GitHub Pages from the `main` branch, using the root folder.
